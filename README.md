# Calculator

A simple and basic calculator project built to perform common arithmetic operations.

## 📌 About

This was one of my first web development projects, created to practice the fundamentals of HTML, CSS, and JavaScript while building a functional calculator.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Simple and easy-to-use interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone the repository.
2. Open `calculator.html` in any web browser.
3. Start using the calculator.

No installation or additional dependencies are required.

## 📂 Project Structure

```text
calculator/
└── calculator.html
```
